# Archived experimental entry points

These scripts record earlier ABMIL, PIBD, CTransPath, level-0 patching, and
parallel-fold diagnostics. They are intentionally outside the active
`scripts/` directory because none is the canonical MRePath paper experiment.

Paths inside the archived scripts reflect their original locations and are not
maintained as runnable interfaces. Use `scripts/run.sh` or
`scripts/run_coadread.sh` for the active paper-contract reproduction.
